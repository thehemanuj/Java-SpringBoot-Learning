1. JDBC

In this section we will be learning about what is jdbc and why do we use it, JDBC stands for Java Database Connectivity and it's a code or architecture that allows us to connect the Database to the Code(Application). We do this to make our data permanent and save it in the database otherwise the data will be wiped off with every session. The basic step is to first get the Drivers from the dependency platform(here we have used Maven to download our dependency) and we have downloaded the MySql drivers. After that we need to reload the pom.xml file to get the dependency in our code.

Not to forget thing , we need to keep the MySql Engine running in our system.

2. Create JDBC

Now since we have JDBC drivers in our system , we can learn how to create a connection with the Database. The Steps for the same are:
  • Import the libraries
  • Load the drivers → This is not needed with latest JDK
  • Register the Driver
  • Create Connection
  • Create Statement
  • Execute Statement
  • Close the connection
Importing the libraries
import java.sql.*;
Loading the drivers
This is done by reloading the pom.xml files and getting the necessary dependency.
Registering the drivers
This is an optional step and we can leave it for now and is not needed for higher JDK.
Creating a connection
for this we need 3 main components which are
  1. Username
  2. Password
  3. url
Username is often the name of the account that we use to get into the sql its something like root Password is ofcourse your password to log into the database url is the main entry point which builds the connection and its something like "jdbc:mysql://127.0.0.1:3306/springboot"

"jdbc:{Server Engine}://{url where server is running}/{name of db}" After the above steps , we need to get the connection Connection con = DriverManager.getConnection(username,password,url); If con is not null then this means that we have got the connection.
